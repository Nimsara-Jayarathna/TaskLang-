# TaskLang++

TaskLang++ is a small domain-specific language for describing task scheduling
and automation workflows. This university assignment implements a lexer and
parser using Flex and Bison, with semantic validation written in C.

The program validates TaskLang++ source files. It does not execute shell
commands, run tasks, or perform real scheduling.

## Features

- Task definitions with `TASK name { ... }`
- Exactly one `RUN "command"` statement per task
- Optional schedule statements:
  - `EVERY DAY AT "HH:MM"`
  - `EVERY WEEK AT "HH:MM"`
  - `AT "HH:MM"`
- Optional dependency statements:
  - `AFTER taskName`
  - `DEPENDS ON taskName`
- Optional condition statements:
  - `IF success(taskName)`
- Flexible statement order inside a task body
- Semantic checks for:
  - Duplicate task names
  - Missing `RUN` statements
  - Duplicate `RUN`, schedule, dependency, or condition statements
  - Unknown dependency references
  - Unknown `success(taskName)` references
  - Invalid `HH:MM` time strings
  - Circular dependencies

## Requirements

Install Flex, Bison, GCC and Make.

On macOS with Homebrew:

```sh
brew install flex bison gcc make
```

On Debian/Ubuntu:

```sh
sudo apt update
sudo apt install flex bison gcc make
```

## Build

```sh
make
```

This creates an executable named `tasklang`.

## Run

Use input redirection to validate a TaskLang++ source file:

```sh
./tasklang < samples/valid_daily.tl
```

Expected successful output begins with:

```txt
Parsing completed successfully.
Semantic validation completed successfully.
```

## Sample Programs

Valid samples:

```sh
./tasklang < samples/valid_daily.tl
./tasklang < samples/valid_workflow.tl
./tasklang < samples/valid_weekly.tl
```

Invalid samples:

```sh
./tasklang < samples/invalid_syntax_missing_run.tl
./tasklang < samples/invalid_unknown_dependency.tl
./tasklang < samples/invalid_circular_dependency.tl
```

The invalid samples demonstrate missing required statements, unknown dependency
references and circular dependency detection.

## Clean Generated Files

```sh
make clean
```

This removes the executable and files generated by Flex and Bison.
